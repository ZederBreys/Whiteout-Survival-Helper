<h2>Как развивать экспертов</h2>

<p>У каждого эксперта есть:</p>

<ul>
    <li>4 навыка, которые прокачиваются в Академии с помощью Книг Знаний</li>
    <li>1 талант, который усиливается по мере роста уровня ваших с ним отношений</li>
</ul>

<h2>Примеры экспертов</h2>

<p>Вот несколько экспертов, с которыми вы можете столкнуться:</p>

<p><strong>Агнес</strong> — ускоряет строительство, даёт дополнительные задания разведки, увеличивает выносливость, приносит полезные ресурсы. Развивает параметр «Защита войск».</p>

<p><strong>Сирилла</strong> — специализируется на событии «Охота на медведя». Увеличивает урон, расширяет размер рейда и повышает награды за участие.</p>

<p><strong>Ромул</strong> — один из сильнейших боевых экспертов, усиливает армию.</p>

<h2>Советы по прокачке</h2>

<p>Не распыляйте ресурсы. Лучше сфокусироваться на прокачке одного-двух экспертов, которые закрывают ваши главные потребности (например, Агнес для стабильного развития, Сирилла для охоты, Ромул для PvP).</p>

<p>Планируйте прокачку. Используйте ускорения для навыков, которые отмечены значком академической шапочки.</p>

<p>Копите печати. Не тратьте их бесцельно — лучше копите для преодоления 10-уровневых этапов, на которых разблокируются множители характеристик.</p>

<p>Система экспертов — это мощный инструмент, который может значительно ускорить развитие вашего города. Главное — грамотно распределять ресурсы и не забывать развивать отношения с каждым советником. Если у вас остались вопросы по конкретным экспертам или механикам, спрашивайте — помогу разобраться!</p>
