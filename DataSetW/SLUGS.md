# SLUGS.md

Стабильный словарь URL.

Каждый slug создаётся один раз и не меняется без крайней необходимости.
Если папка переименована — slug обновляется. Иначе — неизменен.

---

## Правила формирования slug

1. Русские названия транслитерируются в латиницу.
2. Пробелы заменяются на дефисы.
3. Скобки, кавычки и спецсимволы удаляются.
4. Заглавные буквы → строчные.
5. Slug для событий: не включает префикс «Информация по событию»,
   только название самого события.

## Алгоритм автоматической транслитерации

Если папка не найдена в словаре — slug генерируется автоматически.
Алгоритм:

```
вход: "Новый Раздел"

1. Замена символов по таблице:
   а → a    б → b    в → v    г → g    д → d
   е → e    ё → yo   ж → zh   з → z    и → i
   й → j    к → k    л → l    м → m    н → n
   о → o    п → p    р → r    с → s    т → t
   у → u    ф → f    х → kh   ц → ts   ч → ch
   ш → sh   щ → shch ъ → ""   ы → y    ь → ""
   э → e    ю → yu   я → ya

2. Заменить пробелы и спецсимволы на "-".
3. Удалить повторяющиеся дефисы.
4. Привести к нижнему регистру.
5. Обрезать дефисы по краям.

выход: "novyj-razdel"
```

При автоматической генерации парсер выводит warning:
`⚠ Slug "novyj-razdel" сгенерирован автоматически. Добавьте в словарь.`

## Гарантии стабильности

1. **Slug не зависит от имени папки напрямую.** Он хранится в словаре.
   Переименование папки НЕ меняет slug — нужно явно обновить словарь.

2. **Slug уникален.** Валидатор проверяет уникальность при сборке.
   Дубликат slug'а → ошибка сборки.

3. **Slug не содержит спецсимволов.** Только `[a-z0-9-]`.

4. **Slug не длиннее 80 символов.** Если длиннее — сокращается
   (с предупреждением).

5. **События имеют префикс в URL:**
   `/e/{event-slug}/` — это не slug события, а полный URL.
   Slug события не включает `e`.
