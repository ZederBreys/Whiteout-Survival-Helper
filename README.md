# WOS Helper

Статический информационный сайт по игре **Whiteout Survival** (помощник и справочник). Содержит справочные разделы, описания событий и таблицу героев. Контент хранится в папке `DataSetW/` и автоматически собирается в статический сайт генератором Eleventy. Источник данных — игровой сервер lolka.gg (автор rip_Ghoul).

## Возможности

- **Статический сайт** — генерация HTML на основе шаблонов Nunjucks с помощью Eleventy.
- **Контент из `DataSetW/`** — разделы и события описываются папками с изображениями и текстовыми файлами-описаниями, парсер автоматически превращает их в страницы.
- **Адаптивная вёрстка** — интерфейс перестраивается под ширину экрана (точки 600, 768 и 1024 пикселя).
- **Сайдбар на десктопе** — навигация по разделам и событиям с иконками, подсветка активного пункта.
- **Нижняя навигация на мобильных** — компактное меню «Главная / Разделы / События».
- **Полнотекстовый поиск Pagefind** — страница `/search/`, русская локализация интерфейса, вызов по `Ctrl`/`Cmd` + `K`.
- **Таблица героев** — раздел «Все герои»: колонки (герой, войска, поколение, способ получения, мета-роль и стратегическая ценность), разбивка по поколениям.
- **Изображения WebP с `srcset`** — конвертация в WebP (320 и 574 пикселя) при сборке, ленивая загрузка.
- **Полноэкранный просмотр изображений** (PhotoSwipe) — увеличение, перетаскивание, зум колесом мыши, pinch-to-zoom, свайпы, навигация стрелками, закрытие по `Esc`.
- **SEO** — `sitemap.xml`, `robots.txt`, Open Graph-разметка, JSON-LD (хлебные крошки `BreadcrumbList`), канонические URL и мета-описания.
- **Favicon и PWA-манифест** — набор иконок всех размеров, `apple-touch-icon`, `site.webmanifest`.
- **Локальные SVG-иконки Lucide** — встроены в шаблоны, без внешних запросов на время выполнения.
- **HTML-разметка внутри контента** — текстовые описания могут содержать HTML (списки, таблицы, цитаты), который сохраняется при генерации.
- **Дополнительно** — страница 404, хлебные крошки, навигация «предыдущая/следующая» между страницами.

## Технологии

| Технология | Назначение |
| --- | --- |
| Eleventy (11ty) | статический генератор |
| Nunjucks | шаблоны страниц (`.njk`) |
| HTML / CSS | разметка и стили (переменные, адаптивная сетка) |
| Vanilla JavaScript | интерактив: просмотр изображений, поисковый шорткат |
| Pagefind | полнотекстовый поиск |
| @11ty/eleventy-img | генерация WebP и `srcset` |
| Lucide (lucide-static) | локальные SVG-иконки |
| PhotoSwipe | полноэкранный просмотр изображений |

## Структура проекта

```
Whiteout Survival Helper/
├── .eleventy.js            # конфигурация Eleventy (коллекции, шорткоды, passthrough)
├── .gitignore
├── README.md
├── package.json            # зависимости и скрипты сборки
├── DataSetW/               # исходный контент
│   ├── <разделы>/          #   папки разделов: изображения + файлы-описания
│   └── Информация по событиях/  # события
├── src/                    # исходники сайта
│   ├── _data/              # глобальные данные (парсер DataSetW)
│   ├── _includes/          # фрагменты шаблонов (навигация, SEO, иконки)
│   ├── _layouts/           # базовый макет
│   ├── assets/             # CSS, JS (включая PhotoSwipe), иконки сайта
│   ├── *.njk               # страницы: главная, разделы, события, поиск, sitemap, 404
│   ├── robots.txt
│   └── site.webmanifest
├── scripts/                # парсер контента и вспомогательные скрипты
│   ├── parser/             # чтение DataSetW, разбор описаний, слаги
│   └── format-content.js
└── public/                 # результат сборки (генерируется, не хранится в git)
```

## Установка и запуск

```bash
npm install          # установка зависимостей
npm run build        # сборка сайта и индекса поиска Pagefind
npm run serve        # локальный сервер с пересборкой (http://localhost:8080)
npm run dev          # то же, что и serve
```
